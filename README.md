# Velira Studio — локальна реалізація

База: два оригінальні архіви з позначкою git 726aec 53. Це завершена окрема реалізація поточної задачі, відновлена з робочої копії turn 109; варіант velira-dark-codex не використовувався.

## Запуск

Розпакуйте `velira-without-examples-source.zip` і `velira-original-media.zip` в одну теку: обидва містять спільний корінь `velira/`. Потрібно об'єднати їх, не замінювати одну теку іншою.

У терміналі перейдіть у `velira` і запустіть:

```sh
python3 -m http.server 4192 --bind 127.0.0.1
```

Відкрийте http://127.0.0.1:4192/. Якщо порт зайнятий, виберіть інший вільний, крім 4176. У середовищі виконання preview уже працює на 4192.

Це статичні HTML/CSS/JS. Немає npm-залежностей або кроку збірки. Шрифт Onest, зображення й відео локальні. Обидва ZIP потрібні для всіх відеоприкладів.

## Збережене

15 оригінальних HTML-маршрутів, UA/EN, контактні адреси, тарифні дані, оферти, правові тексти, відео та Flow demo. `desktop.html`, `tablet.html`, `mobile.html` відкривають адаптивну сторінку сайтів.

26.09.2026 / turn138: на прохання власника прибрано всі приклади сайтів: портфоліо головної, галереї й перший екран сторінки сайтів та трьох її копій, макет YOUR.BRAND у послугах. Навігація веде до послуг і наповнення сайту; нумерацію секцій оновлено. Фіолетове тло, неонові заголовки, опис бота й автоматизації збережено. Неактивні вихідні медіафайли залишені в архіві; сайт їх не показує.

Основні зміни: `assets/css/studio.css`, `assets/css/studio-secondary.css`, `assets/js/studio.js`, `assets/js/studio-locales.js`, `assets/js/studio-metadata.js`, HTML-сторінки. Візуальні матеріали створено CSS/SVG без платної генерації. Чистий знак — `brand/velira-mark-clean.svg`.

## Локальні форми

На localhost/127.0.0.1 форми валідуються, показують повідомлення про preview і не надсилають заявку. Оригінальний серверний обробник збережено; його реальна доставка на production не перевірялася й не активувалася. Жодних облікових даних або секретів до пакета не додано. Flow зберігає розрахунки лише в localStorage цього браузера.

## Motion

WAAPI: поява рядків 780 мс, stagger 90 мс, вся вступна послідовність 1170 мс. CSS: світло 24с на desktop,28с наmobile; зерно нерухоме. `prefers-reduced-motion` дає статичний читабельний варіант. Природне прокручування, доступні hover/focus/press стани.
